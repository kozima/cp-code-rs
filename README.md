# cp-code-rs

競技プログラミングで使用する Rust の個人用のコード集です。
主に AtCoder の生成 AI ルールに従って事前にコードを公開しておく目的で作成しています。

すべての実装が十分にテスト・整理されているとは限らず、未完成のものも含まれます。
また API や実装は予告なく変更されます。

## Requirements

- Rust 1.89 or later
- Edition 2024
